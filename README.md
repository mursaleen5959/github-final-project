# Simple Interest Calculator

A beginner-friendly project that calculates **simple interest** and the **total amount payable or receivable** using a principal amount, an annual interest rate, and a time period.

## Project Overview

The Simple Interest Calculator helps users estimate how much interest accumulates on a principal amount when interest is calculated only on the original principal (not compounded).

## Features

- Calculate simple interest from three inputs: principal, annual interest rate, and time.
- Calculate the total amount (principal + interest).
- Display results in an easy-to-understand format.

## Formula

**Simple Interest:**

\[
SI = \frac{P \times R \times T}{100}
\]

**Total Amount:**

\[
A = P + SI
\]

Where:
- **P** = Principal amount (initial money borrowed or invested)
- **R** = Annual interest rate (percentage)
- **T** = Time in years
- **SI** = Simple interest
- **A** = Total amount

## Example

Suppose you invest **$1,000** at an annual interest rate of **5%** for **3 years**.

```text
Principal (P):       $1,000
Annual Rate (R):     5%
Time (T):            3 years

Simple Interest:     (1000 × 5 × 3) / 100 = $150
Total Amount:        $1000 + $150 = $1150
```

## How to Use

1. Open or run the calculator in your project's environment.
2. Enter the **principal amount**.
3. Enter the **annual interest rate** as a percentage.
4. Enter the **time period** in years.
5. Calculate to see the simple interest and total amount.

> **Note:** The exact setup or run command depends on the programming language and files used in your implementation.

## Input Guidelines

- Enter a principal amount greater than or equal to zero.
- Enter the interest rate as a percentage (for example, `5` for 5%).
- Enter time in **years** (for example, `0.5` for six months).
- Use the same currency throughout the calculation.

## Learning Objectives

This project demonstrates how to:

- Accept and process numeric input.
- Apply a mathematical formula in a program.
- Perform basic arithmetic operations.
- Format and present calculated results.

## Important Note

This calculator uses **simple interest**, not compound interest. It assumes a constant annual rate over the specified period and does not include fees, taxes, or additional payments.
