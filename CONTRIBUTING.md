# Contributing to Simple Interest Calculator

Thank you for your interest in contributing to the **Simple Interest Calculator** project!

**All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.** Whether you're new to open source or an experienced developer, your input can help make this project better.

## Ways to Contribute

- **Report bugs:** Describe the issue, how to reproduce it, and what you expected to happen.
- **Fix bugs:** Submit a change that resolves an existing issue.
- **Improve documentation:** Clarify instructions, correct mistakes, or add helpful examples.
- **Suggest enhancements:** Propose improvements to usability, accessibility, or functionality.
- **Share ideas:** Start a discussion about features or approaches that might benefit users.
- **Improve tests:** Add or update tests to help keep calculations accurate.

## Getting Started

1. Fork the repository and clone your fork.
2. Create a branch for your change:
   ```bash
   git checkout -b feature/short-description
   ```
3. Make your changes, keeping them focused and easy to review.
4. Test your changes. For calculations, verify the simple interest formula:
   ```text
   Simple Interest = (Principal × Annual Rate × Time in Years) / 100
   ```
5. Commit your work with a descriptive message.
6. Push your branch and open a pull request describing your changes.

## Reporting Bugs

When opening an issue, please include:

- A clear description of the problem.
- Steps to reproduce it.
- The expected result and the actual result.
- Any relevant inputs, error messages, or screenshots.

## Pull Request Guidelines

- Explain what your change does and why it's useful.
- Reference any related issue, if applicable.
- Keep code and documentation clear and consistent with the existing project.
- Avoid unrelated changes in the same pull request.
- Be respectful and constructive when discussing feedback.

## Questions and Suggestions

If you're unsure where to start, open an issue to ask a question or propose an idea. Feedback of every kind is appreciated.

Thank you for helping improve **Simple Interest Calculator**!
